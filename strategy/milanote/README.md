# undressed.socials — the feed operating system

The full Milanote build for the `moodporn undressed` board, written out as content
so it can be pasted straight in.

Ten boards. Every board is one file. Not inspiration — an operating system.

**`BUILD-PROMPT.md`** is the handover brief: paste it into a Claude session that has
Milanote access and it will build these ten boards into the existing `moodporn undressed`
board — additively, without deleting anything that's already there. It also works as a
build brief for a human.

---

## How to read these files

| Markdown | Milanote |
| --- | --- |
| `# Heading` | the board name |
| `## Heading` | a **column** on that board |
| `### Heading` | one **note** inside that column |
| body text under a `###` | the note's content |
| `> quote` | a line meant to be set large (Gluten Black) — a headline card, not body copy |

So: one file → one Milanote board. One `##` → one column. One `###` → one note.

## Fastest way to build it

1. In Milanote, create the ten boards first, in order, using the names in `00-board-map.md`.
2. Open a board. Copy the `##` column names for that file, paste them onto the board —
   Milanote offers **"create separate notes"**; take it, then convert each to a column.
3. Then go note by note: copy a `###` title + its body, paste into the column.
   Milanote keeps the first line as the note title.
4. Boards `03`–`05` and `09` are the ones you will actually work in daily.
   `01`, `02`, `08` are the ones you re-read before writing anything.

Anything already on the existing board slots in under `07 Visual World` — the existing
references get **grouped by visual principle**, not left in one pile. That regrouping is
the point of board 07.

## Decisions taken while writing this

Three places where the strategy and the existing brand system disagreed. Each is easy
to reverse — flagged so the choice is visible rather than buried.

**1. Everything is lowercase.**
The CI (`css/colors_and_type.css`, `js/data.jsx`) is lowercase throughout — *"truth has
never looked this good."*, *"we strip brands bare."* The strategy draft was written in
sentence case. All post copy here is lowercase to match the brand. The only uppercase is
system vocabulary: **DESIRE / THINKING / MAKING** and the series names
(**BORROWED CODES**, **UNDRESSED**, **IF IT WERE OURS**), which read as stamps, not sentences.

**2. "we make brands feel wanted" sits *under* the existing line, not instead of it.**
`we strip brands bare. then we make them loud.` is already the brand's line and it is on
the site. The new line answers *why you strip* — it is the layer beneath, and it belongs
in captions and bios, not on the homepage hero. Both live on board 01.

**3. The three-layer system absorbed the five pillars from the earlier draft.**
DESIRE / THINKING / MAKING are the layers. Borrowed Codes, Undressed, If It Were Ours,
The Work are **series** that sit inside them (board 06). Tips, trends, news, BTS and case
studies are **formats**, never pillars — they always sit inside a layer. This is what stops
the feed fragmenting.
